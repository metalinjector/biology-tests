# Олимпиада под микроскопом

Интерактивный тренажёр по олимпиадам по биологии для 7–8 класса. В основе — три настоящих тура:

| Олимпиада | Заданий | Типы заданий |
|---|---|---|
| Городской этап, 7 класс, 2014/2015 | 35 | один ответ, ответ с предварительным выбором, пропущенное слово, соответствие, схема микроскопа, таблица соцветий, промыслы |
| Школьный этап, 8 класс, 2016/2017 | 25 + 4 бонусных | верные суждения, термины, 20 тестов, соответствия, сравнительная таблица членистоногих, тренажёр на перенос знаний |
| Олимпиада, 8 класс, 2018/2019 | 32 + 4 бонусных | 29 тестов (номера 22 в бланке нет), агротехнические приёмы по иллюстрациям, ротовые аппараты насекомых по фото, признаки листа, тренажёр с открытыми задачами |

## Как это работает

1. Ученица читает вопрос и отвечает: выбирает вариант, вписывает слово, собирает соответствие или заполняет таблицу.
2. «Проверить». Если ответ неверный, тренажёр подаёт сигнал: карточка вздрагивает, неверное подсвечивается красным, звучит короткий сигнал, на телефоне срабатывает вибрация. Для вписанных слов есть подсказки на типичные ошибки («придаток» вместо «придаточным», «линька» вместо «метаморфоз» и т. п.).
3. После первой попытки открывается **«Подробный разбор»**: плавно разворачивающаяся вкладка с правильным ответом и полным разбором из исходных материалов. Сохранены все рисунки (47 схем и 3 рисунка из условий), таблицы разбора вариантов, блоки «Внимание», «Как запомнить», «Ловушки», «Олимпиадный горизонт». Вариант, который выбрала ученица, отмечается в разборе.
4. Где нужно вписать слово, под полем есть кнопка «Показать первую букву», затем «вторую» и «третью» (слово целиком не раскрывается). Открытые буквы видны и в самом поле.
5. Переключатель **«Ответы сразу»** над вопросом позволяет открыть разбор с правильным ответом ещё до попытки. Настройка запоминается.
6. Звёзды: с первой попытки 3, со второй 2, дальше 1. Подсказка по буквам снимает одну звезду. Если открыть разбор до верного ответа, звёзд за вопрос не будет.
7. В конце — «диплом» I, II или III степени по набранным звёздам, разбивка по заданиям и «Работа над ошибками».

В олимпиаде 2018/2019 разбор сам допускает второй ответ в нескольких заданиях (тест 10, практические задания 2 и 3). Такие ответы тоже засчитываются, а тренажёр поясняет, какой ответ основной. Открытые задачи тренажёра решаются в черновике и сверяются с ключом: ключ открывается без штрафа, затем ученица сама отмечает «ответила верно» или «были ошибки».

Дополнительно: карточки для самопроверки и словарь корней терминов из всех олимпиад (переворачиваются), памятки ловушек, экспресс-шпаргалка, ключи ответов (под спойлером), случайный факт «Знаешь ли ты?» на главной, тёмная тема, управление с клавиатуры (`А`–`Е` или `1`–`9` — выбор варианта, `Enter` — проверить, `←` `→` — листать).

Прогресс хранится только в браузере ученицы (localStorage).

## Как открыть

- **Одним файлом:** `dist/olimpiada-pod-mikroskopom.html` — всё внутри (задания, рисунки, стили), открывается двойным щелчком, можно переслать как вложение.
- **Как сайт:** любая статическая раздача корня репозитория, например GitHub Pages (Settings → Pages → Deploy from a branch → выбрать ветку и папку `/root`) или локально:
  ```bash
  python3 -m http.server 8765
  # открыть http://localhost:8765/
  ```

## Устройство

```
index.html               страница
assets/css/app.css       оформление (светлая и тёмная тема, телефон)
assets/js/app.js         логика: проверка ответов, разборы, звёзды, карточки
assets/js/data.js        задания и разборы (генерируется, руками не править)
assets/img/              рисунки из условий (7 класс и 8 класс 2018/2019)
source/                  исходные HTML-разборы трёх олимпиад
tools/build_data.py      source/ → assets/js/data.js
tools/bundle.py          сборка единого файла dist/…html
tools/selftest.mjs       проверка в браузере
```

Текст условий и разборов не перепечатывается вручную: `tools/build_data.py` переносит его из `source/` вместе с SVG-рисунками. Ключи ответов заданы в скрипте явно и при каждой сборке сверяются с итоговыми матрицами ответов, строками «Ответ:»/«Эталонный ответ:» и экспресс-шпаргалкой из исходников; при расхождении сборка останавливается.

## Проверка

```bash
python3 tools/build_data.py          # сборка данных + сверка ключей
python3 tools/bundle.py              # единый файл
python3 -m http.server 8765 &
node tools/selftest.mjs              # нужен Playwright с Chromium
```

`selftest.mjs` проходит **все 100 вопросов** через интерфейс эталонными ответами (каждый должен получить «Верно!» и три звезды), проверяет, что в каждом разборе столько же рисунков, сколько в исходнике, что неверный ответ подаёт сигнал, что разбор не открывается до первой попытки (а с «Ответы сразу» — открывается), что подсказка по буквам открывает не больше трёх букв и снимает звезду, что работают звёзды, «подсмотренный» ответ, работа над ошибками, карточки и памятки, что засчитываются допустимые альтернативные ответы и работают открытые задачи, что картинки загружаются, а на ширине телефона страница не прокручивается вбок.
